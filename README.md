# Flexbox-exercises
This repository contains a series of exercises focused on building foundational CSS Flexbox layout skills. Each folder under `foundations/flex` contains a specific layout task. Follow the instructions inside each exercise folder's `README.md` file to complete the tasks.

## Exercises

Complete the exercises in the following order:

1. **01-flex-center**  
   Learn to center elements both vertically and horizontally using Flexbox.

2. **02-flex-header**  
   Build a simple responsive header layout with Flexbox.

3. **03-flex-header-2**  
   Expand on the previous header layout by adding additional elements and alignment.

4. **04-flex-information**  
   Use Flexbox to layout informational cards with consistent spacing and alignment.

5. **05-flex-modal**  
   Design a modal with centered content and structured layout using Flexbox.

6. **06-flex-layout**  
   Create a more complex Flexbox layout involving nested flex containers and responsive behavior.

7. **07-flex-layout-2**  
   Apply your Flexbox knowledge to a full-page layout structure with header, main content, and sidebar.
